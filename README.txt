DESCRIPCIÓN
Este proyecto consiste en una página web responsiva creada con HTML5, Bootstrap,
CSS y JavaScript. La página se adapta a diferentes tamaños de pantalla y presenta
ejemplos interactivos de los conceptos estudiados en el módulo.

CONTENIDO DEL PROYECTO
- index.html: contiene la estructura semántica de HTML5.
- css/style.css: contiene los estilos personalizados y una media querie.
- js/script.js: contiene las variables, tipos de datos, arreglos, objetos,
  condicionales, bucles y funciones.
- img/logo-laboratorio.svg: imagen utilizada en el encabezado.
- video/laboratorio.mp4: grabación de pantalla de un mínimo de tres minutos.

CONCEPTOS DE JAVASCRIPT PRACTICADOS
- Declaración de variables.
- Tipos de datos string, number y boolean.
- Salida de información en la página y en la consola.
- Creación y recorrido de arreglos.
- Creación y lectura de objetos.
- Condicionales if, else if y else.
- Bucles for, while y do...while.
- Definición y ejecución de funciones.
- Eventos mediante addEventListener.

PRUEBAS
La página fue probada en un navegador web. También se utilizó la consola de
desarrollador para verificar los mensajes generados por JavaScript y comprobar
que no existieran errores.
